# Dummy data cases

Made by `dev_tools/make_dummy_data.py`. All people, companies, buildings, PANs, GSTINs, phone numbers, e-mails and law firms are made up; PIN codes and place names are real. Phone numbers start with 55 or 56, so they cannot be real Indian mobile numbers; e-mails use the reserved example.com, .net and .org domains; Neo CIF IDs and Global collateral Nos are far above the range the LMS uses. Run the tool on this data with `--dummy`.

As in the LMS, an application can have several collaterals (one loan secured by several properties), but a Collateral ID belongs to one application only. Borrowers are per application; owners are per collateral and can be the same, different, or overlap between the collaterals of one application.

Every loan is active (Loan Status A); there are no cancelled (X) or closed (C) loans.

`Dummy required details answers.xlsx` holds what a person would type in the required-details file (every individual's gender and father's / mother's name, and the values the hand-made cases leave out); `dev_tools/fill_dummy_required_details.py` types it in after step 1.
