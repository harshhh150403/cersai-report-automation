# Dummy data cases

Made by `dev_tools/make_dummy_data.py`. All names, PANs, phone numbers, e-mails and law firms are made up; PIN codes and place names are real. Run the tool on this data with `--dummy`.

As in the LMS, an application can have several collaterals (one loan secured by several properties), but a Collateral ID belongs to one application only. Borrowers are per application; owners are per collateral and can be the same, different, or overlap between the collaterals of one application.

Applications APPL00090036 to APPL00090060 are ordinary records, generated so that CKYC has exactly 200 rows (`CKYC_ROWS` in the script). Each one has its COLLATERAL rows and a title report for every collateral that agrees with the LMS.
